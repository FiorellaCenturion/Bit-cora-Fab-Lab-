# Módulo 1 • Herramientas de documentación

En este módulo correspondiente a la semana 1 lo que estuvimos viendo y trabajando principalmente fueron acerca de las diversas herramientas que podemos utilizar para lo que sería nuestra documentación durante todo el proceso de pasantía, entre estas herramientas se encuentran GitHub junto con Gitbook, también el uso de programas para lo que sería la edición de material audiovisual tanto de imágenes como de vídeos hasta de prints de pantalla en tiempo real, toda esta exploración en conjunto nos sirve para poder en el futuro no solo conocer nuevas herramientas sino que también agilizar el proceso de documentación de cada avance dentro de esta pasantía! c:
