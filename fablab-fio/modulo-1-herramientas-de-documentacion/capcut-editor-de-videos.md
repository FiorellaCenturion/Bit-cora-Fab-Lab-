# Capcut • Editor de videos

## <mark style="color:$info;">**¿Qué es CapCut y para qué se utiliza?**</mark>

CapCut es un software de edición de videos que permite crear y modificar contenido audiovisual de una manera sencilla y práctica. Se puede utilizar desde una computadora o un celular, y es muy popular para editar videos destinados a redes sociales como TikTok, Instagram y YouTube.

<figure><img src="../.gitbook/assets/images (1).png" alt=""><figcaption></figcaption></figure>

Una de sus principales ventajas es que combina herramientas de edición básicas y avanzadas con funciones automatizadas que facilitan el trabajo, incluso para personas que no tienen mucha experiencia editando videos.

**Principales funciones de CapCut**

* **Edición de videos:** permite cortar, dividir, unir y reorganizar clips para construir una secuencia audiovisual.
* **Textos y subtítulos:** permite añadir títulos, textos animados y subtítulos automáticos para facilitar la comprensión del contenido.
* **Transiciones y efectos:** ofrece recursos visuales para conectar escenas, crear movimientos y darle dinamismo al video.
* **Música y efectos de sonido:** permite incorporar canciones, narraciones y sonidos para acompañar las imágenes.
* **Corrección de color:** cuenta con ajustes para modificar el brillo, el contraste, la saturación y otros aspectos visuales.
* **Velocidad del video:** permite acelerar o ralentizar clips para generar distintos efectos.
* **Eliminación de fondos:** ofrece herramientas para separar personas u objetos del fondo en determinados tipos de videos.
* **Herramientas con inteligencia artificial:** según la versión y el plan, incluye funciones como subtitulado automático, eliminación de silencios, seguimiento de objetos y otras tareas automatizadas.
