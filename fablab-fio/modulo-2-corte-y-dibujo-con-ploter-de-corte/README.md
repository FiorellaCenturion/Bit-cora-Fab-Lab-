# Módulo 2 • Corte y dibujo con Plóter de corte

En este módulo estuvimos trabajando con distintas herramientas de fabricación digital, principalmente con el uso del plotter de corte y dibujo, el diseño paramétrico a través de Rhinoceros y Grasshopper, y algunas páginas web que permiten generar dibujos vectoriales. A lo largo de las actividades, fuimos explorando las posibilidades que ofrecen estas herramientas para crear diseños a partir de imágenes, fotografías y diferentes formas geométricas, que posteriormente podían ser llevados a un soporte físico mediante el corte o el dibujo con bolígrafo.

También estuvimos trabajando con el vectorizado de imágenes para la creación de stickers multicapa y con el componente Image Sampler de Grasshopper, que permite utilizar una imagen como base para generar diferentes composiciones. Además, exploramos algunas plataformas para generar dibujos y patrones de manera digital, incluyendo diseños de ciudades y propuestas relacionadas con el _Penplot Art_.

Algo que me pareció interesante de este módulo es que pude comprender que trabajar con este tipo de herramientas implica bastante prueba y error, ya que no siempre se obtiene el resultado esperado en el primer intento. Muchas veces es necesario ir probando diferentes configuraciones, modificar parámetros y volver a realizar el proceso hasta conseguir el resultado que buscamos. Esto me ayudó a entender que equivocarse también forma parte del aprendizaje y que experimentar con las herramientas es importante para conocer sus posibilidades y encontrar nuevas formas de resolver un diseño.
